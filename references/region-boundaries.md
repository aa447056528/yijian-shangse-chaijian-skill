# 部位识别、边界定位与标签验收

本文件是执行方法与选路规范，不是随包提供的分割引擎。开始分区时读；修正时只重查相关段。目标是用最少必要操作得到正确部位，而不是为每件临时开发算法。

分区基于已检查的 WORKING，而非默认不可更改的原高模。遇到形体缺陷先按 [重建与优化](mesh-reconstruction.md) 处理，再更新面标签和锚点。

## 1. 先选适合证据的路线

### 通用模型的输入选路

先区分用户要的是语义部位拆分、颜色实体化，还是为打印尺寸/装配新增切口。同色可有多个物理件，一个部位也可按制造需要再拆；不同目标不能互相代替。若原模没有真实接缝，记录新增切口的设计依据，不伪称识别出了原有部位。

| 输入结构 | 优先依据与保留项 |
|---|---|
| 已有独立件、对象层级、面集或可靠材质 | 验证真实连通与接触后复用；不先合并、重网格再重新识别 |
| 人物、动物、植物等融合有机形体 | 按该模型建立部位与邻接，验证根部和遮挡；不套用头/躯干/四肢的固定件数或对称假设 |
| 硬表面道具、建筑或机械外观模型 | 优先利用壳体边界、孔槽和已有装配关系；区分装饰线与结构接缝，保护功能尺寸，不能用全局平滑消除棱线 |
| 几何平滑、只有纹理/顶点色分区 | 排除烘焙阴影、反光及纹理接缝，确认颜色意图后生成有厚度的色体；颜色聚类本身不决定部件 |
| 薄片、中空壳、穿孔或嵌套结构 | 先确认内外表面和拓扑，允许多个边界环；不能套用单个封口平面或把内壁认作残片 |

轴向、左右、尺度与最小特征均从当前输入确认；可复用接口类型和验证方法，不复用其他模型的切割坐标、阈值、种子或拟合半径。未覆盖的输入类型先做局部代表验证，再推广。

| 输入情况 | 优先做法 | 升级或切换条件 |
|---|---|---|
| 已有独立物体、面集或材质标签 | 检查侧后覆盖和真实连通后复用，修正局部 | 标签只覆盖可见正面、材质跨部位或对象仍融合时继续识别 |
| 单个或少量无标签融合模型，目标部位明确 | 优先验证三维正负种子与受约束传播，先粗归属、后修边；见 [快速分区流程](seed-guided-regions.md) | 工具不支持必要约束时改用可执行的三维选面/涂抹；相邻表面混淆时补侧后证据 |
| 部位由明显凹槽、折线或曲率转折分开 | 在语义范围内追踪三维交界，结合局部法向和凹凸信息 | 路径穿过完整球面、端帽或避开真实根部时，检查候选点、权重和限制区域 |
| 外表面光滑，主要由颜色/语义区分 | 用可靠纹理或多视图部位识别，映射到可见的工作网格面，再检查隐藏区 | 几何无对应折线时不强行找凹槽；遮挡不自动判为背景 |
| 少量融合、遮挡或工具识别失败 | 在正确侧视/剖面中补三维引导，限制可选连通表面，再局部修正标签 | 若仍跨层或证据冲突，先检查源形体；必要时限定局部修形，而不是不断换投影坐标 |

这些路线可以在同一模型中组合。已有明确交界时可直接描三维边界；采用种子路线时，不必先给每件画完整闭环。大量不同模型或人工标注成本明显更高时，再评估多视图AI粗分区，比较安装、推理、修正和验收的总成本。工具存在不等于它在当前模型上有效。

单个眼球或深沟通过，不能证明同一阈值适合整模。推广前在边界证据不同的区域做代表验证，例如浅根部、平滑分色区和遮挡连接；选择允许/禁止传播的三维区域。跨区泄漏或同一部位被褶皱割裂时，退回该局部，不反复全模调阈值。

## 2. 建立完整部位假设

完整交付先列整模部位及相邻关系；方法验证只列目标件、必要邻件和影响装配路径的区域。每个部位标出确定属于它的面、确定属于邻件的面，以及需要判断的边界带。边界带宽度按局部特征尺寸和网格间距选择，不能用一个固定毫米值套全部模型。

正面轮廓不能代替完整部位。检查凸起的侧壁和端帽、球体侧后表面、耳后或发根遮挡，以及部件底面是否仍被归入主体。深沟也可能是同一部位的装饰纹，须结合语义判断。

视角按疑点选择：先整模总览，再仅为遮挡和不确定边界补侧视、背视、斜视或剖面。无需为每件机械渲染固定数量图；但未被任何证据覆盖的区域不得默认通过。

## 3. 在正确表面内定位交界

### 融合根部的局部归属关口

遇到袖子贴住衣身、耳机贴住脸或头发等融合接触，先在原工作网格上标出完整目标、邻件及未确定边界带，再构造实体。平面、包围盒、圆柱或拟合曲面可以限制搜索范围，也可在已确认的隐藏接口处使用；其布尔结果闭合，不证明切口就在真实接缝。镜像和坐标阈值同样只能生成候选。

对疑难接口保存以下局部证据，并绑定工作网格与标签版本：

- 原形体或纹理与对比色标签使用相同视角；曝光应能看清边界，不用高光过曝掩盖错色。
- 在原位检查相邻双方，再隐藏目标件查看邻件剩余面，并独立查看目标件。肩顶、袖根、内垫、背面、发梢等实际遮挡处须可见；总览或外侧完整不能代替内缘检查。
- 记录是否漏掉目标的端帽/根部、是否夹带邻件、接缝是否穿过同一部位的完整曲面。已发现任一问题即FAIL；缺证据的段保留UNKNOWN。逐段证据齐全才可通过，不固定要求每个简单零件都渲染同一套视图。

将“切进别的部位”与“两个实体体积重叠”分开检查：即使交集体积为零、缝隙连续，语义仍可能错误。错分产生的孤岛先追溯原表面归属；不能为了单连通而删除、并入最近部件或加连接桥。只有原形体连接确实存在缺陷，且归属已确认，才进入局部重建。

用户指出穿帮时，先定位并复核受影响双方，暂停它们的下游实体化与导出；按[恢复与局部失效](recovery-manifest.md#恢复与局部失效)撤销错误通过状态。不要仅改切刀角度后继续全模流程。

**三维引导与贴面。** 从看得见目标交界的视角取候选点，保存所属面、深度及可用法向。正面射线的首个命中仅表示正面可见表面，不能定位其后的附着根部。最近点仅是候选；检查是否仍在指定连通区域、是否跨过眼睑/耳廓等遮挡面，以及相邻样本深度和法向是否异常变化。凹槽本身可以有法向突变，不能因变化大就把真实槽抹平。

**几何证据。** 在局部邻域检查凹槽、法向转折和形体连续性。高曲率可能来自凸脊、皱纹或网格噪声，不等于部件边界。先判断预期交界类型；计算特征时结合局部尺度，必要时只平滑用于分析的法向/曲率，不改变原外表面。

**受约束连接或区域划分。** 使用现有路径、区域生长或图分割工具时，先确认其实际支持的约束。路径应留在候选边界带；已确认的部位内部和邻件内部应保护，不能让捷径穿过。几何交界可将可信凹槽设为优先，并惩罚偏离交界、跨错误表面和方向不连续；语义边界使用多视图/纹理证据。边长可作平顺与长度约束，不应是识别未知边界的唯一目标。无需同时实现所有算法，选择工具真实支持且适合当前证据的一种。

普通最短路可以连接**已确认**且限制区域内无歧义的交界点；它不负责判断部位。将线投到最近顶点并连成闭环，只能证明线在网格上。没有可靠特征算子时，改为在适当视图补少量三维引导并逐段检查，不能把无约束最短路包装成自动识别。

**一致性。** 检查同一边界在相关视图中是否仍落在交界，正面正确而侧面穿过凸起内部必须回退。镜像可以生成候选，另一侧须重新贴合。邻件共用一套边界定义，不分别描线留下重叠或缺口。

投影落在外棱、回弯侧壁反复漏分或需要试切时，读[遮挡根部与共享切面](occluded-root-boundaries.md)：用源面连接关系核对截线分支，区分圈选辅助闭合与真实接缝，并处理切面端点退化及索引迁移。该路线是可选局部方法，不保证自动完成分区。

## 4. 批量写面标签，再分开检查三种正确性

种子路线可先在允许区域内传播候选面集，把存在竞争、约束冲突或缺乏证据的边界带保留为UNKNOWN；此时不要求先有完整闭环，也不能标记分区通过。已有边界路线则在边界约束下传播。两种路线都保护正/负样本，禁止跨越已确认屏障；多部位争用同一面时联合修正共享边界，不能用执行顺序覆盖前一标签。允许边界有多个环或多邻件，不能强迫每件都是一个简单圈。

轻量代理的标签转到工作网格时，限制位置、法向、所属连通表面和可见性；邻近薄层不能仅凭欧氏距离对应。发现小特征被代理吞掉，恢复该局部分辨率或在工作网格直接分析。

| 检查 | 通过依据 | 不能替代它的结果 |
|---|---|---|
| 标签结构 | 有效工作网格面有且仅有一个已知标签或明确UNKNOWN；索引版本一致；部位数量、邻接和连通符合预期 | 颜色渲染看起来正常 |
| 部位语义 | 目标部位完整，侧壁/端帽/根部/遮挡区有证据，无邻件夹带；接缝符合形体或指定分色意图 | 100%归属、无重复、分出指定件数、闭环成功 |
| 接缝几何 | 共享边界连续，未跨层，密度与形体匹配，没有锯齿、毛刺及不合理捷径 | 语义归属大致正确或网格闭合 |

前两项通过才能标记REGIONS_READY。第三项可在提取表面后集中整理，通过后再标记SURFACES_APPROVED、进入接口设计。检查颜色标签覆盖后，必要时切回灰模核对形体；不要凭阴影色差判标签。

最小记录：工作网格版本、种子/约束版本（使用时）、各部位面集与颜色/物理件映射、相邻双方、边界依据及所用路线、UNKNOWN面、三类检查状态和对应视图。置信程度用有依据的高/中/低或待核实即可，不编造概率。

## 5. 按错误类型修正，而不是反复描线

| 现象 | 先检查 | 有针对性的处理 |
|---|---|---|
| 正面正确，侧面球体或端帽漏色 | 候选是否只有正面首命中、边界是否穿过部位内部 | 增加能看到侧后根部的视角，在正确连通表面补引导或语义约束，局部重分 |
| 明显沟槽旁出现偏移线 | 点是否在错误侧，连接是否只最小化长度 | 限制到真实交界带，补几何特征或局部引导，复核邻件正/负样本 |
| 耳后、眼角突然跳到邻面 | 最近点是否跨层，源形体是否有桥接/自交 | 限制面集、法向与连接方向；必要时剖面定位真实融合，不继续平面投影 |
| 位置正确但沿三角形边呈锯齿 | 标签已正确而网格边方向不合适 | 由共享贴面曲线局部切分三角形或重拓扑；记录新面至源面的对应，双方同步更新 |
| 标签完整、件数正确但明显错色 | 只检查了结构统计，没有语义证据 | 标签候选保持DRAFT；项目阶段按仍有效证据回退，补全语义检查，不能用补洞、加厚或布尔修复标签错误 |

先定位错误来自证据、映射、路径、传播还是网格离散，保持未受影响的面标签。失败分类与尝试边界按[主流程的有界返修规则](../SKILL.md#4-有界返修与验收交付)执行。局部视角或引导不足时补齐证据；缺必要约束时，切换上表中有实质不同依据的路线并先验证疑难局部。避免无边界的算法研发；局部三维引导可执行时应实际补点、约束候选带并核对侧后根部；形体有错时实际验证局部重建。没有可执行替代时明确具体能力缺口，而不是把一个简化方法失败归因于模型无法拆分。

规则曲面拟合可以辅助检查部位完整性，但不能单独决定语义边界；球面与眼睑等邻件相接时尤其如此。不得为了修正标签，直接把投影中多层顶点推到同一拟合面。
