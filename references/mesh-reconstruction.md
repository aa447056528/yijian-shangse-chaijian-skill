# 形体重建与网格优化

输入是参照模型、目标外观和部位假设；输出是可用于分区和实体构造的工作形体。这里的优化包括修形、重建和网格组织，不只是减面。用户只要求编辑 skill 时不执行建模。

## 1. 先决定保留什么、修哪里

先看整模剪影和比例，再查看疑点的侧后、灰模高光或剖面。区分真实纹理、有效褶皱与三角化条纹、鼓包、折痕、薄片、错误融合。阴影异常先比较平滑/平面着色和实际截面；法向显示问题不应直接触发几何重建。

按区域记录：缺陷、保护特征、拟用操作、影响邻件、验收视图。优先修会影响部位辨识和接口位置的问题；仅接缝带的网格方向问题留到共享边界明确后处理。目标图未覆盖的背部依现有形体及三维连续性判断，不能用正面投影压平。

| 情况 | 处理选择 | 验证重点 |
|---|---|---|
| 形体正确、网格仅冗余 | 特征保护的自适应减面；必要时只做分析代理 | 剪影、凹槽、薄边和小件是否还在 |
| 局部噪声、条纹或三角面起伏 | 约束边界及保护区的局部平滑/重拓扑 | 体积收缩、沟槽被磨平、有效褶皱损失 |
| 错误连接、凹陷、薄片或塌陷 | 切除问题面并重建局部连续曲面 | 接口邻域、法向、厚度及相邻部位关系 |
| 简单部位明显畸形 | 按多视图轮廓与根部约束重建该部位 | 完整侧壁、根部、遮挡及表情，不单靠球/椭球拟合决定边界 |
| 大面积融合与拓扑混乱 | 在副本上验证较大范围重网格，再恢复特征 | 分辨率是否吞小件、合并薄层、填死深沟；局部方案不可用的理由 |

先处理一个有代表性的缺陷区，验证操作没有损伤保护特征，再批量处理同类区域。操作尺度由缺陷宽度和需保留的最小特征决定，不预设统一减面比例、体素大小或平滑次数。不反复全模重网格叠加误差。

## 2. 三份网格的职责

- SOURCE：只读参照及回退依据，保留输入哈希、尺度与坐标。
- WORKING：修复后的当前建模基准。可继承原网格，也可包含局部重建面；外观和工程判断都绑定该版本。
- PROXY：可选计算代理，用于加速分析。不可因处理快就直接替代交付网格。

先在小件、浅沟和薄结构验证代理，失败时恢复局部分辨率或直接在 WORKING 分析。代理与工作网格的映射受位置、法向、连通与可见性约束；不把空间最近面当成可靠语义归属。局部重建改变拓扑后，原有面索引、曲线锚点和接口证据在影响区域失效，必须更新。

修复后的面不要求逐面对应原模：新增面记录 `rebuilt`、来源区域和生成定义；未改变区保留映射。不能为了满足旧索引把成果贴回有缺陷的原高模。局部重建与分析代理是两个不同产物，分别记录。

## 3. 与分区交替推进

若凹边分区把有效褶皱当成部位边界，修正分区证据，不磨掉褶皱。若错误融合导致边界不存在，先重建合理形体，再定义共享边界。若只是边界落在三角网格上呈锯齿，确认语义后局部切面或重拓扑，让相邻双方共用连续边界。

保留已通过区域，仅使受影响标签、接缝与接口失效。局部修改后重新查看相关邻件与整模轮廓，不用全模重跑代替影响判断。

## 4. 工作形体验收

在相同相机、尺度和中性着色下比较修复前后。查看正面表情、侧面体积、背部连接及疑点剖面；确认缺陷确实去掉，未新增鼓包、尖刺或压扁。几何检查覆盖受影响面的退化、法向、非流形与自交疑点，未执行项如实记录。

保留区域可测表面偏差与剪影偏移；明确修形区域按目标外观和连续性验收，不能用“更接近坏原模”作为通过条件。阈值依据已知尺寸与最小特征；尺度未定时记录相对值，不虚报毫米精度。平均偏差小也不能掩盖局部薄边消失。

工作形体通过才标记 WORKING_READY；这不代表分区、接口或可打印性通过。后续修复若改变已验收形体，更新版本并复核影响范围。诊断报告、彩色预览或低面数都不能替代实际修复结果。
