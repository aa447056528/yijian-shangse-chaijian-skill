# 工具选择：辅助计算，不替代设计

先检查已有工具与输入标签，按具体缺口选择。不绑定Tripo或其他云平台，不要求某个私有插件。经用户授权可以下载、安装并验证成熟工具；检查来源、许可证、版本、硬件与资源需求，优先隔离环境，不默认下载全部模型权重。

| 能力 | 可选工具/方式 | 验证重点 |
|---|---|---|
| 网格读取、真实连通件、属性标签 | Blender及可靠网格库 | 单位、坐标、原面索引是否保留 |
| 形体修复与工作网格重建 | Blender局部网格编辑、重拓扑、约束平滑或局部替换；大范围重网格先验证 | 剪影和表情、薄结构、沟槽、邻件连续性及修复前后对照 |
| 批量面归属 | 已有面集；三维涂抹/选面配合支持正负种子的区域生长或图分割；必要时评估SAMesh、SAMPart3D | 是否真正支持正负种子、允许区域/禁止跨越边、未确定面及局部更新；检查完整部位和总耗时 |
| 交界定位与局部修正 | 已安装的网格特征选择、受约束路径/区域工具或贴面曲线操作 | 工具实际使用了哪些边界证据；能否防止跨层、跨部位和绕过凹槽 |
| 表面提取与接口生成 | Blender网格操作及已验证脚本 | 配对环、内斜过渡、平面、厚度和闭合 |
| 必要实体布尔 | Blender或用户已安装的成熟布尔工具 | 作用范围、刀体可靠性、异常体积与残片 |
| 缺失形体补全 | 局部确定性重建；确需时可选HoloPart等模型 | 隐藏几何合理、尺度一致、形体偏移和重叠 |
| STL回读 | 本包scripts/check_stl_exports.py | 仅基础拓扑/尺寸/底面统计，不是完整制造认证 |

SAMesh公开路线将多视图分割映射回三维；SAMPart3D公开运行流程包含对象相关训练；HoloPart需要预分区输入。它们不是可以互换的一键打印工具。当前版本、安装条件和许可在采用时查官方仓库；不因论文效果而声称在用户模型上有效。

对已有用户插件先检查功能和副作用，再在副本做有界实测。手工插件可用于曲线、斜面和布尔执行，但不假称它具备自动语义分面能力。不随skill重新分发第三方代码或权重。

原模质量不足时先按 [重建与优化](mesh-reconstruction.md) 建立工作形体。工具清单不等于已实现能力；普通减面、阈值分区和布尔插件不能替代形体与语义判断。

分区路线按 [边界定位与标签验收](region-boundaries.md) 选择。先检查现有工具能否完成当前局部，不因缺少自动语义引擎直接停工，也不临时开发整套通用引擎。若只具备最近点、普通最短路与洪泛，须把它们标为映射/传播工具；边界仍需另外识别和验证。主代理可自行作有界局部几何选择，不把常规部位判断全部转交用户。

种子路线按 [快速分区流程](seed-guided-regions.md) 检查能力。Face Sets、材质、顶点组或涂色只是标注/显示载体，不自动等于受约束分割器。负样本作为硬约束与只增加惩罚不是同一能力，需实际核对；工具强制给所有面分类时，由执行流程保留未验证边界带为UNKNOWN。当前环境没有该算子时如实记录，可转为直接三维标注加局部边界编辑；不把普通洪泛或最近点包装成已经实现的正负种子分割，也不临时为每件开发一套引擎。

## 实测门槛

一次检测只说明工具存在；运行成功只说明接口可调用。要成为可复用能力，还须用相应输入验证结果和速度：记录输入哈希、版本、参数、目标覆盖、耗时、返修量及导出回读。分别标记分面、表面整理、实体接口及最终观感是否通过。

生产任务不默认演变成通用算法研发。工具缺失或试验失败时明确缺口；不将配置问题当算法失败，也不将简单几何通过推广到复杂融合角色。
