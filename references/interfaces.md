# 主代理的接口设计与布尔决策

输入是本轮范围内已经提取并检查过的部件表面、共享边界和邻接图；方法验证只要求目标件及必要邻件满足前置条件。先明确材料归属和装入路径，再选择几何运算。不是每个部件都要布尔，也不是每个接口都要销。

## 一份共享定义生成双方

为每个接口记录：

- interface_id、相邻part_id、共享边界版本；外露面保护范围。
- 插入件与主体，装入/退出方向、组装先后；多邻件的避让关系。
- 外边界C、向内部斜收的过渡I、内部贴合平面F；深度、缩进及最小壁厚依据。
- 材料归属、间隙种类与数值、收边方式；直接构造还是布尔，以及作用对象和顺序。

C留在合理外观接缝，I形成连续斜坡，F形成真实胶接面积。必要时局部采用多个内部平面，但不削平外观来迁就制造。沿退出方向看截面不能产生扣住主体的凸缘或倒钩。

共享边界只整理一次。保持两侧环点对应，控制密度，凹部缩进先检查自交，不用极角排序或凸包抹掉凹部。不将密集噪声外环拉向中心形成放射状折纹。空间窄时缩短过渡或改变深度，不能硬塞统一参数。

默认保留中间胶面，入口按需要作小直倒角；曲面确需连续高光时才用圆角。避免对高密度布尔碎边统一加大bevel。倒角模型仍须检查两侧真实边缘。

## 运算选择

| 情况 | 主代理选择 | 必须检查 |
|---|---|---|
| 可靠表面片和共享接口环 | 直接连接规整过渡、封内部面，生成双方互补接口 | 封面方向、闭合性、邻件体积归属 |
| 插入件进入主体，需要凹槽 | 同一接口定义构造闭合负形，对主体差集；插入件取对应实体 | 实际单边/轴向余量、槽口薄唇、主体壁厚 |
| 候选实体有超出所属范围的体积 | 用明确的闭合归属体求交或裁剪 | 没有误吞外观和有效细节 |
| 融合源存在额外连接桥 | 增加局部共享切面，实体化差集后按连通性分离 | 切断全部桥，外扩刀面不经过邻件 |
| 定位结构需要连接到部件 | 对真实相交的可靠实体并集 | 有效连接截面，Join不等于实体融合 |
| 多个补全件相互重叠 | 先确定重叠区归属和组装顺序，再配对裁剪 | 不依赖生成模型自动保证无重叠 |

不得仅凭包围盒判定表面单值。拟用轮廓挤出时确认作用范围内无折返及遮挡，并检查实际三维接缝；不把厚圆柱作为所有眼窝的默认负形。

## 局部贴面刀的后备流程

仅用于分面已有明确意图、直接封面不适用的局部，不代替批量确定表面归属。

1. 沿接缝布置少量三维锚点，插值后限制局部/法向重新贴面，检查跳面及过冲。
2. 构造O外扩带，使刀面末端到达实体外。O是工具而非零件裙边；不能机械沿表面法向伸出而划伤相邻眼袋、袖口等形体。
3. 构造C→I→F的内斜过渡及平面，检查截面无折返。F拉平，C仍贴真实边界。
4. 将同一刀面对称加厚为闭合刀体，差集后按真实连通件分离。厚度t是总移除带，名义每侧t/2；不等于每侧t，曲面实际间隙另测。
5. 验证双方切口及组装，不另描一套相邻接口。

## 修形与数值边界

先清理交界带及独立部件本身的畸形，再构造接口。只平滑切线不能修好其下的坏表面。限制修形到确定的连通表面；不能把投影下多层顶点同时压到一个Y/Z曲面。简单畸形眼球或装饰可局部替换，但需保护眼睑、表情及整体比例。

开口表面片不能直接用作实体布尔刀。对刀体和结果检查闭合、法向、退化、自交疑点；异常包围盒扩大、切刀残留、体积突变立即回退。不按小岛大小统一删除真实部件。

代表接口记录源标签、刀面/配合定义、两侧网格、灰模正反及装配视图、实际耗时。失败按[主流程的有界返修规则](../SKILL.md#4-有界返修与验收交付)处理。未经实测的实现不能作为已经可复用的算子推广。

## 构造后的提前检查

代表件按几何类型选取；嵌套接口连同母件和相关邻件检查。推广前检查完整实体，包含封面与原外表面相交；只查接口自身不够。共用边界不自动保证实体无倒扣或间隙足够。

法向偏移在凹部和薄边可能折叠，固定外环的间隙通常是渐变值，不能报告为全程恒定间隙。区分侧壁、轴向和可见缝余量。体积重建或其他后处理后，重新测量相关间隙、形体偏差和胶面；旧参数仅是构造定义。
